# Inventario Castores

## Entorno

- IDE: IntelliJ IDEA Community 2026.1
- Lenguaje: Java 17 (Eclipse Temurin 17.0.19)
- DBMS: MySQL 8.0.46
- Servidor: Apache Tomcat 9.0.118

## Pasos para correr la aplicacion

1. Clonar el repositorio.
2. Crear la base de datos `inventario_castores` en MySQL.
3. Ejecutar el script `SCRIPTS/creacion_tablas.sql`.
4. Configurar Tomcat 9 en IntelliJ.
5. Hacer deploy del WAR.
6. Ingresar a [http://localhost:8080/inventario-castores](http://localhost:8080/inventario-castores).
